# Kiểm kê luồng xuất tài liệu

Kiểm kê từ định nghĩa quy trình hiện có. Mọi trợ lý dưới đây có công cụ đọc lại file thực tế và cổng kiểm tra file mới trước bàn giao. Đây là kiểm kê khả năng và hợp đồng chất lượng, không phải chứng nhận đã chạy toàn bộ quy trình với mô hình thật.

| Chức năng | Quy trình | Loại file được khai báo |
|---|---|---|
| Văn thư NĐ 30 | Soạn văn bản mới | docx |
| Văn thư NĐ 30 | Dựng lại từ bản nháp | docx |
| Văn bản Đảng HD 05 | Soạn dự thảo văn bản Đảng | docx |
| Văn bản Đảng HD 05 | Rà dự thảo văn bản Đảng | docx |
| Tổng hợp báo cáo | Tổng hợp báo cáo kỳ | docx, xlsx |
| Tổng hợp báo cáo | So hai phiên bản báo cáo của một đơn vị | xlsx |

| Luyện ngoại ngữ | Sửa một bài viết | docx |
| Soạn giáo án | Soạn kế hoạch bài dạy | docx |
| Soạn giáo án | Làm slide bài giảng | pptx |
